# 对话界面尺寸优化

## 目标
增大 NPC 与玩家对话区域，提升阅读和输入体验，并适配不同窗口尺寸。

## 范围
- 调整 `scenes/dialogue_ui.tscn` 的底部对话面板布局。
- 保持现有对话逻辑、输入和关闭行为不变。

## 验收标准
- 对话面板高度明显增加，文本区域可展示更多内容。
- 控件随窗口宽度伸缩，不依赖固定 1280px 宽度。
- 输入框、发送和关闭按钮仍位于面板底部且可用。

## 验证
- 使用 Godot headless 导入并检查场景资源。
- 检查变更 diff，确认仅涉及对话 UI 布局。

## 风险与回滚
- 仅修改场景布局；若出现布局问题，可回退该场景文件。
